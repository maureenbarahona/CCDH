# Cámara de Comercio Digital de Honduras (CCDH)

Plataforma oficial de la Cámara de Comercio Digital de Honduras, diseñada para impulsar el comercio digital y la innovación tecnológica en la región.

## 🚀 Características

- **Diseño Mobile-First**: Optimizada para dispositivos móviles, escalando fluidamente a pantallas de escritorio.
- **Modo Oscuro/Claro**: Adaptabilidad al sistema y toggle manual para preferencia del usuario.
- **Accesibilidad**: Cumplimiento con estándares WCAG (contraste, foco visible, semántica).
- **Animaciones Suaves**: Micro-interacciones y efectos parallax sutiles.
- **Performance**: Carga rápida con optimización de imágenes y recursos.
- **Seguridad**: Enlaces externos seguros y buenas prácticas de privacidad.

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica.
- **CSS3 (Variables)**: Estilos modernos, Grid/Flexbox, y animaciones.
- **JavaScript (ES6+)**: Interactividad y lógica de aplicación.

## 📦 Instalación y Ejecución

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/maureenbarahona/CCDH.git
    cd CCDH
    ```

2.  **Abrir en el navegador:**
    Simplemente abre el archivo `index.html` en tu navegador favorito.

    O usa un servidor de desarrollo simple (requiere Python):
    ```bash
    python3 -m http.server
    ```

## 🌐 Despliegue

Este proyecto está configurado para desplegarse en **GitHub Pages**.

1.  Asegúrate de tener la rama `gh-pages` actualizada.
2.  En GitHub, ve a *Settings > Pages*.
3.  Selecciona la rama `gh-pages` como fuente.
